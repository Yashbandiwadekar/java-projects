# Java Fresher Projects

Three small console-based Java projects built to practice core OOP, exception handling, and the Collections framework — no frameworks, no external dependencies, just plain Java (JDK 21).

| Project | Focus |
|---|---|
| [01 – Library Management System](01-library-management-system/) | Inheritance & polymorphism, custom exceptions, `HashMap`/`ArrayList` |
| [02 – Student Result Management System](02-student-result-management-system/) | Validation exceptions, `LinkedHashMap`, sorting with `Comparator` |
| [03 – Bank Account Simulator](03-bank-account-simulator/) | Abstract classes, polymorphic withdrawal rules, transactional transfer logic |

Each project is self-contained under its own `src/` folder with no build tool — compile and run directly with `javac` / `java` (see each project's README for exact commands).
